# 💱 Currency Converter —  агрегатор и конвертер курсов валют

## О приложении

Сервис автоматически собирает курсы покупки и продажи **USD** и **EUR**
у десятков банков, публикующих данные на ru.myfin.by, и хранит их в
собственной базе данных, обновляя раз в 30 минут в фоновом режиме.
Поверх этих данных построено REST API и веб-интерфейс, которые позволяют:

- сравнивать актуальные курсы разных банков в одном месте;
- находить банк с самым выгодным курсом покупки или продажи;
- конвертировать сумму по курсу конкретного банка в обе стороны
  (рубли → валюта и валюта → рубли);
- управлять доступом через регистрацию, аутентификацию и роли
  пользователей (обычный пользователь / администратор).

Проект был реализован «под ключ»: от проектирования API и базы данных
до контейнеризации, развёртывания на собственном VPS с доменом и
HTTPS, и разработки веб-интерфейса.

🔗 **Демо-версия:** [currency-converter.ru](https://currency-converter.ru)
📄 **Документация API:** `/docs` (Swagger UI)

## Стек технологий

**Backend**
Python 3.13 · FastAPI · Uvicorn / Gunicorn · Pydantic v2 / pydantic-settings

**База данных**
PostgreSQL · SQLAlchemy (async ORM, asyncpg) · Alembic (миграции)

**Аутентификация и безопасность**
JWT (access + refresh токены) · passlib (хэширование паролей) ·
httpOnly-куки · ролевая модель доступа (RBAC)

**Сбор данных**
aiohttp · BeautifulSoup4 · APScheduler (фоновые задачи по расписанию)

**Тестирование**
Pytest · pytest-asyncio · unittest.mock (AsyncMock/MagicMock) · httpx

**Инфраструктура и DevOps**
Docker · Docker Compose · Nginx (reverse proxy) · Let's Encrypt / Certbot
(SSL) · Ubuntu Server (VPS) · Git (feature-branch workflow, Issues, Pull
Requests)

**Frontend**
HTML5 · CSS3 (custom properties, без препроцессоров) · Vanilla JavaScript
(Fetch API)

## Что было сделано

1. **Спроектировал и реализовал REST API** на FastAPI: роутеры для
   пользователей, ролей и курсов валют, с разделением на слои
   router → service → DAO.
2. **Построил асинхронный слой работы с БД** на SQLAlchemy + asyncpg,
   включая универсальный `BaseDAO` с переиспользуемыми CRUD-операциями
   для всех сущностей проекта.
3. **Разработал систему миграций** через Alembic, включая устранение
   реальных конфликтов схемы и синхронизацию состояния БД между
   окружениями.
4. **Реализовал асинхронный веб-парсер** (aiohttp + BeautifulSoup) с
   повторными попытками при сбоях сети, обработкой рекламных редиректов
   и защитой от дублирования банков в источнике данных.
5. **Настроил фоновую синхронизацию курсов** через APScheduler,
   интегрированный в жизненный цикл FastAPI-приложения (`lifespan`),
   с защитой от повторного запуска задачи через `asyncio.Lock`.
6. **Спроектировал бизнес-логику обновления данных** — раздельная
   обработка добавления, обновления и деактивации банков, пропавших из источника, 
   с отложенным удалением вместо мгновенного.
7. **Внедрил аутентификацию и авторизацию**: JWT-токены в httpOnly-куках,
   разграничение доступа по ролям, отдельные защищённые эндпоинты
   для администраторов.
8. **Покрыл проект тестами**: юнит-тесты для чистой бизнес-логики и
   API-тесты роутеров с моками зависимостей и БД.
9. **Контейнеризировал приложение**: `Dockerfile` и `docker-compose.yml`
   для приложения и PostgreSQL, с `healthcheck` базы данных и
   автоматическим применением миграций при старте контейнера
   (`entrypoint.sh`) — деплой сводится к одной команде.
10. **Развернул проект на реальном сервере**: настройка Ubuntu VPS,
    непривилегированного пользователя и SSH-доступа, привязка домена
    через DNS, reverse proxy на Nginx и бесплатный SSL-сертификат
    через Let's Encrypt.
11. **Усилил безопасность продакшн-окружения**: разделение секретов
    по окружениям через `.env`/`.dockerignore`/`.gitignore`, блокировка
    на уровне Nginx автоматических попыток сканирования служебных
    файлов (`.git`, `.env` и т.п.) ботами.
12. **Разработал веб-интерфейс** — одностраничное приложение на чистом
    HTML/CSS/JS без фреймворков: живое табло курсов с сортировкой,
    калькулятор конвертации, виджет лучшего курса и переключаемые
    цветовые темы на CSS custom properties.
13. **Выстроил процесс разработки через Git**: задачи оформлялись как
    GitHub Issues, изменения — через отдельные ветки и Pull Request'ы
    со связкой issue ↔ PR.

## Запуск проекта

### Вариант 1 — через Docker (рекомендуется)

Не требует локальной установки Python и PostgreSQL — только Docker.

```bash
git clone https://github.com/Just-arman/currency_converter_app.git
cd currency_converter_app
cp .env.example .env   # заполнить своими значениями
docker compose up -d --build
```

Приложение будет доступно на `http://localhost:8000`, документация — на
`http://localhost:8000/docs`. Миграции применяются автоматически при
старте контейнера.

### Вариант 2 — локально, без Docker

Требует установленный и запущенный PostgreSQL.

```bash
git clone https://github.com/Just-arman/currency_converter_app.git
cd currency_converter_app
pip install -r requirements.txt
cp .env.example .env   # заполнить своими значениями
alembic upgrade head
uvicorn app.main:app --reload
```
